# Lost and Found Portal

A full-stack college Lost & Found portal built with the MERN stack (MongoDB, Express, React, Node.js).

## Tech Stack

- **Frontend**: React 19, Vite 8, Tailwind CSS v4, React Router v7
- **Backend**: Express 4, Node.js
- **Database**: MongoDB (Mongoose)
- **Authentication**: JWT (httpOnly cookies)
- **File Uploads**: Cloudinary

## Features

- User Authentication (Register/Login/Logout)
- Post Lost/Found Items (with images)
- Search, Filter, and Sort Items
- Item Claiming System (Send, Approve, Reject)
- User Dashboard
